# Zebra College Website

A modern, professional college website built with React + Vite + Tailwind CSS.

## Tech Stack
- React 19 + TypeScript
- Vite 6
- Tailwind CSS v4
- Framer Motion (animations)
- Wouter (routing)
- shadcn/ui components
- React Hook Form + Zod (form validation)

## Run Locally

### Step 1: Install dependencies
```bash
npm install
```

### Step 2: Start dev server
```bash
npm run dev
```

Open: http://localhost:5173

## Pages
- `/` — Home (Hero, Stats, Programs, Testimonials, FAQ)
- `/about` — About Us
- `/courses` — Courses with search & filter
- `/admissions` — Admissions form
- `/placements` — Placement stats
- `/faculty` — Faculty directory
- `/campus-life` — Campus life
- `/gallery` — Image gallery with lightbox
- `/contact` — Contact form

## Features
- Dark mode toggle
- Mobile responsive + hamburger menu
- Animated counters
- Scroll-to-top button
- Loading splash screen
- Framer Motion animations
